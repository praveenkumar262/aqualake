# AquaLake – Unified Data Ingestion Framework

AquaLake is a lakehouse-based data ingestion framework designed to support scalable batch and API-driven data ingestion using Azure Data Factory and Databricks.

## Key Features
- Modular ETL pipelines for batch and API ingestion
- Orchestration using Azure Data Factory
- Data validation and deduplication logic
- Pipeline logging and basic monitoring
- Lakehouse architecture using Delta Lake

## Tech Stack
- Azure Data Factory
- Databricks
- PySpark
- Azure Data Lake
- Delta Lake

## Project Scope
This project demonstrates core data engineering practices such as ingestion, transformation, orchestration, and monitoring in a cloud-based lakehouse setup.
